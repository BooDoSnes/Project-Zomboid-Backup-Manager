# 🧟 Zomboid Backup Manager

Um gerenciador de backups moderno para **Project Zomboid**, desenvolvido em Python com **CustomTkinter**.

O programa permite criar, restaurar e gerenciar backups de mundos **Single-player** e **Multiplayer** de forma rápida, segura e intuitiva.

---

## ✨ Recursos

- ✅ Backup de mundos Single-player
- ✅ Backup de mundos Multiplayer
- ✅ Detecção automática dos mundos
- ✅ Compactação em arquivos `.rar`
- ✅ Restauração com backup de segurança automático
- ✅ Gerenciamento de múltiplos backups
- ✅ Histórico de atividades
- ✅ Configurações personalizáveis
- ✅ Interface moderna
- ✅ Barra de progresso
- ✅ Notificações em tempo real
- ✅ Splash Screen
- ✅ Executável para Windows

## 📦 Requisitos

- Windows 10 ou superior
- WinRAR instalado
- Python 3.14+ (apenas para executar pelo código-fonte)

---

## 🚀 Como executar pelo código

Clone o repositório:

```bash
git clone https://github.com/BooDoSnes/Project-Zomboid-Backup-Manager.git
```

Entre na pasta:

```bash
cd Project-Zomboid-Backup-Manager
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute:

```bash
python main.py
```
